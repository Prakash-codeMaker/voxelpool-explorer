# Included research run

This folder contains the actual exploratory CPU experiment run performed on 2026-10-11.

- `RESEARCH_REPORT.md`: findings, methodology, interpretation and limitations.
- `experiment_bundle.json`: all 72 experiment cases, per-strategy timing samples, correctness data, occupancy metrics, machine/software metadata and selector evaluation.
- `strategy_timings.csv`: flattened per-case/per-strategy timing rows for analysis in Python, R, Excel or a notebook.

Important: this is an exploratory synthetic workload run on one CPU environment, not a published benchmark, not a competitive CPU baseline study, and not evidence of Quadric/GPU performance. Review the report's limitations before reusing any numbers.
